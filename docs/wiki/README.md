# Fonte da Wiki da Agência Benjamin

Este diretório contém as páginas Markdown preparadas para a Wiki GitHub do projeto. A Wiki está
habilitada nas configurações do repositório, mas o GitHub ainda não provisionou o repositório
`landing-agencia-benjamin.wiki.git`: isso ocorre após a criação da primeira página na interface da
Wiki. Assim que existir, copie os arquivos deste diretório para a raiz do repositório da Wiki e
publique-os na branch `master`.

As páginas devem permanecer em português e apontar para `docs/` como fonte técnica detalhada. Ao
alterar fluxos de operação, banco ou segurança, atualize a fonte correspondente e esta Wiki no
mesmo PR.
